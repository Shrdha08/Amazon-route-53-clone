# Route 53 Clone – Frontend

Next.js (App Router, TypeScript) UI built with the Cloudscape Design System.

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npx tsc --noEmit
```

Set `BACKEND_URL` (default `http://127.0.0.1:8000`) to point the `/api/*` proxy at the FastAPI service. See the root README for architecture and API details.
